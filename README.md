# 🧮 Python Calculator

A simple command-line calculator built using Python.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division (with zero division handling)
* Input validation

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/calculator-project.git
   ```

2. Navigate to the folder:

   ```bash
   cd calculator-project
   ```

3. Run the program:

   ```bash
   python calculator.py
   ```

## 📌 Example

```
Enter the first num: 10
Enter the second num: 5
Enter operation (+, -, *, /): *
PRODUCT = 50
```

## 📚 Learning Purpose

This project is built to practice basic Python concepts like:

* Functions
* Conditional statements
* Exception handling
